🧮 Calculadora Java CLI
Um projeto prático desenvolvido para consolidar conceitos fundamentais da linguagem Java, como métodos independentes, manipulação de strings e captura de parâmetros via terminal (args).

🚀 Funcionalidades
A calculadora executa as quatro operações básicas através do terminal:

Soma

Subtração

Multiplicação

Divisão

💻 Como Rodar o Projeto
Para executar a calculadora, utilize o terminal dentro da pasta do projeto:

java src/Calculate.java <operacao> <numero1> <numero2>

Exemplo:
java src/Calculate.java somar 10 5

Saída: 15

🛠️ Tecnologias Utilizadas
Java: Linguagem principal do projeto.

IntelliJ IDEA: IDE utilizada para o desenvolvimento.

Git/GitHub: Controle de versão e hospedagem.
